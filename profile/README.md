# CYBERIA:INTERAKTIV
Video game porting, research and development studio focused on older hardware and open-source development libraries, founded by Rachel Bartmoss ([@faithvoid](https://github.com/faithvoid))

Hack the planet.

## Game Engines
- [wipEout remix](https://github.com/cyberiainteraktiv/wipeout-remix) - Hybrid Wipeout/2097/64/3 engine with modern QoL features, based off of wipeout-rewrite by PhobosLab.
- Survival Engine - Open-source (100% a concept as of right now, no functional code is in this repository!)

## Xbox
- [MotokoX](https://github.com/cyberiainteraktiv/MotokoX) - Oni (2001)
- [wipEoutX](https://github.com/cyberiainteraktiv/wipEoutX) - Wipeout/2097/64 port based on wipEout-remix
- [GeometryX](https://github.com/cyberiainteraktiv/GeometryX) - OpenGW (Geometry Wars)
